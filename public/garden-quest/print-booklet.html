📖 Booklet Print Layout

Generate A4 sheets for double-sided booklet printing. Each A4 has 2 A5 pages. Print, stack, fold in half = perfect booklet!

📋 How to Print

  1. Download the 6 A4 PNG files (3 sheets × front/back)
  2. Print settings: A4 Landscape, Actual Size (100%), Double-sided (flip on short edge)
  3. Print order: Sheet 1 → Sheet 2 → Sheet 3
  4. Stack the 3 printed sheets in order (Sheet 1 on top)
  5. Fold the stack in half — pages will be in correct order!
  6. Staple along the fold if desired
