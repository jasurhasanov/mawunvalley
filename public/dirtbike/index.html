🗺️ Routes

Route A: Morning

Kuta → Prabu Hill → Are Guling Hill → Lancing/Tampah Hills → Selong Belanak → Leendang Lantan → Back to Kuta

Route B: Afternoon

Kuta → Unggut → Selar Hill → Sukadana Village → Awang Area → Sokat Beach → Bumbang Beach → Gerupuk Box Cave → Tanjung Aan Beach → Finish in Kuta

📝 Note: Full-day tours cover both routes. Half-day tours — choose one route.
